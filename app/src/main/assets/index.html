HTML → ANDROID

HTML to APK Builder

Загрузи HTML-файл, укажи название приложения и дождись сборки настоящего Android APK.
Адрес Worker, который будет принимать файлы и запускать сборку.
Лучше квадратная PNG-иконка. Если не загрузить, будет создана стандартная.
Сборка выполняется через GitHub Actions. Для работы нужен настроенный Worker и GitHub token.
